# Language selection

S1 leaves the scope recognizer and the version-space chart frozen. Syntactic copies and programs that accept the same strings are merged. A grammar fit on gold schemas scores operator choice, class width conditional on the class, repeat bounds, optionality, and literal length. Repeat bounds come from the atomic compose languages, where an unobserved longer repeat stays open. A small head on the frozen relational encoder, plus contrast features for width, letter affixes, and same-width retints, judges short strings where the remaining languages disagree. One confident witness stays inside the grammar tie; two that split the same way eliminate a language. Stability, then the language that accepts more boundary strings, breaks a tie the grammar also leaves open.

The checkpoint is chosen on atomic semantic top-1. Held-out composition is scored after that choice. BENCH-C is not scored.
