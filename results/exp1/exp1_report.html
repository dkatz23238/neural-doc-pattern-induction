Experiment 1 findings

Can a frontier model infer a useful regular expression from a handful of examples, or do symbolic systems already close the gap? The score is semantic accuracy on hidden strings, not how similar the regex text is to the gold pattern.

Gate 1 · no

The rule is an 8–10 point gap over the best symbolic system on BENCH-C. The heuristic is at 93.2%. GPT-6 Luna is 95.5% (+2.3 points). GPT-5.6 Terra is 98.1% (+4.9 points). An 8-point clearance would be 101.2%, which is past the top of this metric. No model was trained.

Where the models move the score

Macro accuracy keeps a large easy column from deciding the headline. Terra’s largest gains are hashes (+35.4 points), UUIDs (+23.8), serials (+21.4), and transaction ids (+18.8). It stays within 2 points of the heuristic on every other domain. Luna drops on phone numbers (86.5% against the heuristic’s 99.0%), URLs (73.8% against 92.9%), and bank references (65.7% against 87.6%).

Protocol

Frontier calls used the simple prompt on data/bench_c.jsonl, 554 tasks, 6 visible strings each. Date 2026-09-25. The requested Terra model was gpt-6-terra. That id returns model_not_found. The Terra model on this key is gpt-5.6-terra. Neither model accepts temperature 0: chat completions allows only the default value 1, and the Responses API rejects the parameter, so temperature was omitted.

Default grex matches the memorization floor: it rejects negatives and misses hidden positives. Combined grex (-d -w -r) is the useful grex setting, at 86.6% on BENCH-C. fAST (ICGI 2023, find-abstract-syntax-tree 0.2.1) is wired in, including a translation of its concatenation operator. On this suite it did not finish. Within the cap it returned no expression on the short tasks it was given. A worked example still converts correctly: abc, abcabc, abcabcabc becomes ^(?:abc)+$.

BENCH-C is a curated catalog of document fields. It is not a scrape of private PDFs. Hidden negatives are near-miss mutations outside the gold regex.

Source tables: results/exp1/exp1_report.md and results/exp1/frontier_bench_c.json. No neural model was trained.
